# Explorando o PySpark

Este repositório reúne minhas experimentações iniciais com PySpark, a partir de pesquisas sobre seus conceitos e funcionalidades.

O notebook contém exemplos práticos de criação e manipulação de DataFrames, seleção e filtragem de dados, transformações e agregações, colocando em prática algumas das operações mais comuns da ferramenta.

## Tecnologias

- Python
- PySpark
- Apache Spark
- Google Colab
